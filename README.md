# hxwl-06 显微镜玻片观察

样本、玻片、焦面层与结构结论的可恢复记录库。

## 技术栈

React 19 + Vite + TypeScript + CSS（localStorage 持久化，刷新不丢记录）

## 本地运行

```bash
npm install
npm run dev       # 开发端口 5106
npm run verify    # 领域规则断言（34 项）
npm run typecheck
npm run build
```

## 记录链路

样本 → 玻片 → 焦面层（焦面位置 z/清晰度/补传状态）→ 结构结论，全部可恢复、可追溯（页面底部有操作轨迹日志）。

## 业务规则

1. **每层带焦面位置与清晰度**：同一玻片同一视野内 z(μm) 唯一标识一个焦面层。
2. **清晰度更新触发失效重算**：
   - 同视野的**未确认**结论立即失效，重算到当前最清晰层（清晰度 → z → 登记时间择优），并累加「失效重算」次数；
   - **已确认**结论锁定提交时的原层（sourceLayerId），不参与重算，老师复核看到的层与结论始终一致。
3. **两名观察员同时提交同一视野**：同一结构两条结论**两边都保留并标冲突**，待教师裁决；若该结构已有已确认结论，**后到者不能覆盖**，只挂冲突提示。同一观察员重复提交视为修订本人那条，不产生副本。
4. **补传失败可恢复**：补传失败只改状态，**已登记层保留**，可随时重试；重传同一层（同视野同 z）只更新该层，**不生成副本**。
5. **旧记录先待核**：无焦面信息的旧记录导入后玻片标「待核」，其文字结论标「无焦面」，**补登焦面层并经教师复核**后才转为已复核；无层时复核不能通过。
6. **复核状态三处可见**：玻片详情页顶部、全部玻片的结论列表、课堂统计总览均显示「待核 / 已复核」及结论的冲突、重算、锁定标记。

## 课堂演示数据

- `YP-2026-101` 洋葱表皮：3 个焦面层；「细胞核」已确认锁定 z=18μm，「细胞壁」未确认且误挂 z=12μm 模糊层（改清晰度即可观察重算）；z=24μm 已登记待补传（可演示失败/重试/重传不产生副本）。
- `RX-2026-058` 人血涂片：学生甲与学生丙对「白细胞」结论冲突并存。
- `OLD-2025-017` 草履虫：旧记录迁入，无焦面，待核。
