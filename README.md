# hxwl-06 显微镜玻片观察

样本、多倍率视野与染色观察记录库

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

- 样本 → 玻片 → 视野 → 焦面层 → 结构结论的可恢复记录链（本地持久化 + 操作日志 + JSON 导出）
- 焦面层登记：每层带焦面位置（µm）与清晰度；同一视野同一层号重传原地更新，不生成副本
- 清晰度更新联动：该层未确认结论自动失效并按最佳可用层重算，已确认结论保留原层
- 并发提交：两名观察员提交同一视野时双方记录均保留并标冲突，后到者不覆盖已确认结论
- 补传失败保留已登记层，可重试；重传同一层不生成副本
- 旧记录缺焦面信息自动标待核；视野详情、结论列表、课堂统计均展示复核状态
